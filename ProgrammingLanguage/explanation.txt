The compiler runs through each parsed statement. It performs operations accordingly

AstNode *read_expression() {
	AstNode *pnode = allocAstNode();
	Token *ptok = peek();
	if (ptok->type == TOK_IDENTIFIER) {
		pnode->type = AST_NODE_TOKEN;
		pnode->value.ptoken = ptok;
		advance();
	} else {
		langP_errormsg(ERR_MSG_PLACEHOLDER);
		return null;
	}

	for (;;) {
		Token *ptok2 = peek();
		if (ptok2->type != TOK_OPERATOR) {
			return node;
		}
		AstNode pnode2 = allocAstNode();
		pnode2->type = AST_NODE_EXPRESSION;
		// if op2 < op1
		pnode2->value.expression.op = getop(ptok2);
		pnode2->value.expression.a = pnode;
		pnode = pnode2;
		// if op2 > op1
		advance();

		Token *ptok3 = peek();
		if (ptok3->type == TOK_IDENTIFIER) {
			pnode->type = AST_NODE_TOKEN; // wrong this part
			pnode->value.ptoken = ptok3;
			advance();
		}  else {
			langP_errormsg(ERR_MSG_PLACEHOLDER);
			return null;
		}
	}
	return pnode;
}

The `extern` keyword marks one or more external identifiers (functions? or anything?).
The compiler/linker will load them from an external source, into the background.
When the VM reaches the `extern` keyword, it loads the external values from the background onto the appropriate stack position.
During compilation, the identifier strings are not freed. They are added to pcs->externIdentifiers (Vector<char *>).

i.e. 
extern atoi

PUSHCFUNCTION "atoi"    where PUSHCFUNCTION(name: string): function
